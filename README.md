# Customer Churn Prediction

A machine learning web application that predicts whether a customer is likely to churn using Logistic Regression and Streamlit.

## Features
- Predict customer churn
- Interactive Streamlit UI
- Real-time prediction
- Data preprocessing
- Logistic Regression model

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- NumPy

## Project Workflow
1. Data Cleaning
2. Feature Encoding
3. Model Training
4. Model Evaluation
5. Streamlit Deployment

## Model Used
- Logistic Regression

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
